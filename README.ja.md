# Host Colors — SSH, WSL, Containers & Folders

[English](README.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Italiano](README.it.md) · [Português (Brasil)](README.pt-br.md) · [Русский](README.ru.md) · **日本語** · [한국어](README.ko.md) · [简体中文](README.zh-cn.md) · [繁體中文](README.zh-tw.md)

作業している場所に応じて VS Code のウィンドウに色を付けます: SSH サーバー、WSL ディストリビューション、Dev Container、Codespace、Remote Tunnel、またはプロジェクト フォルダー。本番環境と開発環境、あるいはプロジェクト同士を取り違えることはもうありません。

![プレビュー付きのマネージャー](images/screenshot-manager.png)

## 機能

- **グラフィカルなマネージャー** (`Host Colors: マネージャーを開く`):
  - すべてのホストの一覧と、`~/.ssh/config` にあるホストのワンクリック追加
  - カラー ピッカー、12 色のプリセット、ランダムな色
  - VS Code を模したウィンドウでの **ライブ プレビュー** (アクティブ / 非アクティブなウィンドウ)
  - ステータス バーに表示するカスタム ラベル (例: 「PROD ⚠」)
  - 既定の領域、またはホストごとの領域
- **色を付けられる 9 つの領域**: タイトル バー、コマンド センター、アクティビティ バー、ステータス バー、リモート インジケーター、アクティブなタブ、サイド バーの境界線、パネルの境界線、ウィンドウの枠線。
- **実際のウィンドウでプレビュー**: `色を選択` / `色を付ける領域を選択` で、色にカーソルを合わせたり領域をチェックしたりすると、すぐに適用されます。Esc でキャンセルします。
- **パターン**: `prod-*` は `prod-` で始まるすべてのホストに色を付けます。完全一致の名前がパターンより優先されます。
- ワンクリックで **すべて削除**。すべての色を有効 / 無効にするコマンドもあります。
- ステータス バーのドット: クリックするとクイック メニューが開きます。

![カスタム領域と非アクティブなウィンドウのプレビュー](images/screenshot-zones.png)

## コマンド

| コマンド | 説明 |
|---|---|
| マネージャーを開く | プレビュー付きの完全なインターフェイス |
| 色を選択 (ライブ プレビュー) | ウィンドウでプレビューできるクイック ピック |
| 色を付ける領域を選択 | このホスト用または既定 |
| 色の有効化 / 無効化 | 全体のスイッチ |
| ホストの色を削除 | |
| すべて削除 | すべてのホストを削除し、色を取り除きます |
| このワークスペースの色をクリーンアップ | 残ってしまった色を取り除きます |
| 構成をエクスポート… / 構成をインポート… | 色の設定を JSON ファイルで共有 (インポート時にマージまたは置き換え) |

## SSH 以外: WSL、コンテナー、プロジェクト フォルダー

色は他のウィンドウでも機能します。エントリのキーで適用先が決まります:

| キー | ウィンドウ |
|---|---|
| `prod-server` | SSH ホスト (`~/.ssh/config` と同じ) |
| `wsl:Ubuntu` | WSL ディストリビューション |
| `container:my-app` | Dev Container (フォルダー名またはコンテナー名) |
| `codespace:<名前>` / `tunnel:<名前>` | GitHub Codespaces / Remote Tunnel |
| `folder:c:/projects/shop` | ローカルのプロジェクト フォルダー |
| `folder:prod-server:/srv/app` | リモート環境上のフォルダー |

- フォルダーのエントリはその環境のエントリより優先されます。サーバー全体に色を付けてから、1 つのプロジェクトだけに別の色を付けられます (メニュー → **このフォルダーだけに色を付ける**)。
- ローカル ウィンドウでは、色が設定されたフォルダーでのみステータス バーにドットが表示されます。
- ワイルドカードは同じ種類のキーにだけ適用されます: `*` は SSH ホストのみ、`folder:*/api` は `api` という名前のすべてのフォルダーに一致します。

## 言語

UI は VS Code の表示言語に従います: 英語 (既定)、フランス語、ドイツ語、スペイン語、イタリア語、ポルトガル語 (ブラジル)、ロシア語、日本語、韓国語、簡体字中国語、繁体字中国語。

## クイック スタート

1. ローカルまたはリモート (SSH、WSL、Dev Container、Codespace…) でフォルダーを開きます。
2. リモート ウィンドウ: 左下のドットをクリック → **色を変更**。ローカル ウィンドウ: コマンド パレットから **Host Colors: 色を選択 (ライブ プレビュー)** を実行します (フォルダーに色が設定されるとドットが表示されます)。
3. 色にカーソルを合わせて試し、Enter を押します。

## 手動での設定

```json
"sshHostColors.hosts": {
  "prod-*": "#c0392b",
  "dev-server": { "color": "#27ae60", "label": "DEV", "elements": ["statusBar", "activeTab"] }
},
"sshHostColors.elements": ["titleBar", "activityBar", "statusBar"]
```

## 注意事項

- 接続中のウィンドウだけに色を付けるため、色は **ワークスペース レベル** の `workbench.colorCustomizations` (サーバー上の `.vscode/settings.json`) に書き込まれます。ご自身のカスタマイズは保持され、拡張機能が設定した値だけが削除されます。
- 「すべて削除」の後、開いているウィンドウはすぐに、その他のウィンドウは次に開いたときにクリーンアップされます。
- フォルダーを開いていない場合、VS Code はウィンドウに色を付けられません。ステータス バーのドットのみが表示されます。
- タイトル バーとウィンドウの枠線には `"window.titleBarStyle": "custom"` が必要です (Windows では既定値)。
