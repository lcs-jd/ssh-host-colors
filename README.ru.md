# Host Colors — SSH, WSL, Containers & Folders

[English](README.md) · [Français](README.fr.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Italiano](README.it.md) · [Português (Brasil)](README.pt-br.md) · **Русский** · [日本語](README.ja.md) · [한국어](README.ko.md) · [简体中文](README.zh-cn.md) · [繁體中文](README.zh-tw.md)

Окрашивает окно VS Code в зависимости от того, где вы работаете: SSH-сервер, дистрибутив WSL, Dev Container, Codespace, Remote Tunnel или папка проекта. Вы больше никогда не перепутаете продакшен с разработкой или один проект с другим.

![Менеджер с предпросмотром](images/screenshot-manager.png)

## Возможности

- **Графический менеджер** (`Host Colors: Открыть менеджер`):
  - список всех ваших хостов и добавление в один клик хостов из `~/.ssh/config`
  - выбор цвета, 12 готовых цветов, случайный цвет
  - **предпросмотр в реальном времени** в макете окна VS Code (активное или неактивное окно)
  - своя подпись (например, «PROD ⚠») в строке состояния
  - области по умолчанию или собственные для каждого хоста
- **9 окрашиваемых областей**: строка заголовка, центр команд, панель действий, строка состояния, индикатор удалённого подключения, активная вкладка, граница боковой панели, граница панели, рамка окна.
- **Предпросмотр в реальном окне**: в командах `Выбрать цвет` / `Выбрать окрашиваемые области` цвет применяется сразу при наведении, а область — при отметке. Escape отменяет.
- **Шаблоны**: `prod-*` окрашивает все хосты, имена которых начинаются с `prod-`. Точное имя имеет приоритет над шаблоном.
- **Удалить все** в один клик, а также команда для включения / отключения всех цветов.
- Точка в строке состояния: щелчок открывает быстрое меню.

| Выбрать окрашиваемые области | Для этого хоста или по умолчанию |

## Не только SSH: WSL, контейнеры и папки проектов

Цвета работают и в других окнах. Ключ записи определяет, к чему она относится:

| Ключ | Окно |
|---|---|
| `prod-server` | SSH-хост (как в `~/.ssh/config`) |
| `wsl:Ubuntu` | Дистрибутив WSL |
| `container:my-app` | Dev Container (имя папки или контейнера) |
| `codespace:<имя>` / `tunnel:<имя>` | GitHub Codespaces / Remote Tunnel |
| `folder:c:/projects/shop` | Локальная папка проекта |
| `folder:prod-server:/srv/app` | Папка в удалённой среде |

- Запись для папки имеет приоритет над записью её среды: окрасьте весь сервер, а затем задайте отдельному проекту свой цвет (меню → **Окрасить только эту папку**).
- В локальном окне точка в строке состояния появляется только для папок, у которых есть цвет.
- Подстановочные знаки действуют только в пределах своего типа: `*` относится лишь к SSH-хостам, `folder:*/api` — ко всем папкам с именем `api`.

## Языки

Интерфейс следует языку отображения VS Code: английский (по умолчанию), французский, немецкий, испанский, итальянский, португальский (Бразилия), русский, японский, корейский, китайский упрощённый и традиционный.

## Быстрый старт

1. Откройте папку локально или удалённо (SSH, WSL, Dev Container, Codespace…).
2. Удалённое окно: нажмите на точку внизу слева → **Изменить цвет**. Локальное окно: выполните **Host Colors: Выбрать цвет (предпросмотр)** из палитры команд (точка появится, как только у папки будет цвет).
3. Наводите курсор на цвета, чтобы попробовать их, затем нажмите Enter.

## Ручная настройка

```json
"sshHostColors.hosts": {
  "prod-*": "#c0392b",
  "dev-server": { "color": "#27ae60", "label": "DEV", "elements": ["statusBar", "activeTab"] }
},
"sshHostColors.elements": ["titleBar", "activityBar", "statusBar"]
```

## Примечания

- Цвета записываются в `workbench.colorCustomizations` **на уровне рабочей области** (`.vscode/settings.json` на сервере), чтобы окрашивалось только подключённое окно. Ваши собственные настройки сохраняются: удаляются только значения, заданные расширением.
- После «Удалить все» открытые окна очищаются сразу, остальные — при следующем открытии.
- Без открытой папки VS Code не позволяет окрасить окно: отображается только точка в строке состояния.
- Для строки заголовка и рамки окна требуется `"window.titleBarStyle": "custom"` (значение по умолчанию в Windows).
